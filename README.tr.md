# PHP Not Defteri Uygulaması

Bu proje, PHP kullanılarak geliştirilmiş basit bir not defteri web uygulamasıdır.

## Özellikler
- Not ekleme
- Not listeleme
- Not silme
- PHP ile form işlemleri
- Basit ve sade arayüz

## Kullanılan Teknolojiler
- PHP
- HTML
- CSS
- XAMPP (Apache)

## Kurulum
1. Projeyi `htdocs` klasörüne kopyalayın
2. XAMPP üzerinden Apache servisini başlatın
3. Tarayıcıdan aşağıdaki adresi açın:
http://localhost/php-not-defteri/


## Amaç
PHP backend mantığını ve temel CRUD işlemlerini öğrenmek amacıyla geliştirilmiştir.
