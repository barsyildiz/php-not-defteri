📝 PHP Simple Note App 
Bu proje, PHP ile backend geliştirmenin temel mantığını kavramak amacıyla geliştirilmiş bir not defteri uygulamasıdır.

🚀 Özellikler ve Teknik Yaklaşım
Veri Yönetimi: Veriler bir veritabanı (SQL) yerine, doğrudan sunucu üzerindeki dosya sistemi (File System) kullanılarak depolanmaktadır.

CRUD Mantığı: Uygulama; yeni not oluşturma, listeleme ve saklama süreçlerini kapsayan temel CRUD döngüsünü simüle eder.

🛠️ Kullanılan Teknolojiler
Dil: PHP

Frontend: HTML / CSS

Depolama: Local Text Files (.txt / .json)

💡 Neden Dosya Sistemi?
Bu projede veritabanı yerine dosya sistemi tercih edilmesinin ana nedeni, PHP'nin dosya giriş/çıkış (I/O) işlemlerini derinlemesine öğrenmek ve veri serileştirme (serialization) mantığını pratik etmektir. Bu yaklaşım, sistemin harici bir veritabanı bağımlılığı olmadan çalışmasına olanak tanır.

⚙️ Kurulum
Bu projeyi lokal sunucunuza (XAMPP, WAMP vb.) kopyalayın.

index.php dosyasını tarayıcınızda çalıştırın.
